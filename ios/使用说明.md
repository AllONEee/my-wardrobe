# 点点衣橱 · 使用说明

> 一句话：**用数据看清自己的衣橱**——每件衣服穿了几次、每次穿花了多少钱，
> 哪些是真长期主义，哪些是「假便宜」的冲动消费。
>
> 不需要注册、不需要登录，数据全部存在这台手机上。

## 一、快速开始

### 添加第一件衣物

1. 打开「衣橱」页，点右下角的 **+**
2. 从相册选一张照片（或直接拍一张）——**选完会自动进入抠图编辑器**，
   系统会先把衣服抠出来，背景变成透明的棋盘格
3. 抠得不满意时（编辑器里）：
   - **长按画面里的衣物主体**：只抠出你手指底下那一件（叠穿时很有用）
   - **橡皮擦**：擦掉多余的部分
   - **画笔恢复**：把抠多了的地方涂回来
   - **裁剪**：裁掉不要的边缘
   - 底部可以**撤销 / 重做 / 自动抠图**，右上角可以**重置**
4. 点「确定」回到表单，填上名字（必填）、分类、季节、**价格**、购买日期、尺码、备注
5. 点「保存」

> **价格建议一定要填**。填了价格的衣物才能算单次成本——这是后面所有统计的基础。
> 价格本来是可选字段，不填也能用，只是看不到成本数据。

### 一次加好几件

衣橱页右上角 **⋯ → 批量导入**：从相册一次最多选 **20 张**，
每张会自动抠图、自动猜一个分类，你只需要在列表里核对名字和分类，
改完点「导入 N 件」一次性存进衣橱。

## 二、每天 30 秒：记下今天穿了什么

### 方式 A：拍照记录（最快，推荐）

1. 进「日记」页
2. 点日期下面的 **记照片** → 拍一张 / 选一张今天的穿搭照片
3. 自动进抠图编辑器扣掉背景 → 确定
4. 照片就存到那一天了，**月历格子里会直接显示这个贴图**

那天已经有一条记录但还没照片时，照片会挂到最近那条记录上，不会重复建记录。

### 方式 B：从衣橱里选（数据最准）

1. 「日记」页 → **添加穿搭**
2. 选日期（默认今天）、可选季节
3. 点「+ 添加衣物」从衣橱里勾选今天穿的几件
4. 底部 **「计入穿着次数」开关默认打开**——保存后这几件各 **+1 次**，
   单次成本立刻更新
5. 保存

也可以顺手在「今天的照片」里拍一张，这样既有数据也有照片。

### 关于「计入穿着次数」的完整规则

| 你的操作 | 次数怎么变 |
| --- | --- |
| 新建一条穿搭记录（开关打开） | 关联衣物各 **+1**，「最近穿着」记为这天 |
| 编辑这条记录，加进来一件 | 只对**新加的那件** +1 |
| 编辑这条记录，拿掉一件 | 只对**拿掉的那件** −1 |
| 把开关关掉 / 删掉这条记录 | 之前加过的次数**自动回滚** |
| 在「试衣间」里摆一套并保存搭配 | **不计次**（摆造型 ≠ 今天穿了） |

> 这样设计是为了让次数尽量真实：只有「记了某天穿了这套」才会计数，
> 而删掉记录、改错记录时不会留下虚高的数字。

### 衣橱页快捷 +1

在「衣橱」页**点卡片的空白处**（不是图片），这件衣服就 +1 次，
提示条里带 **「撤销」**，点错了能退回来。

## 三、单次成本：这个 App 的主角

**单次成本 = 价格 ÷ 穿着次数**。它回答的是：每次穿这件衣服，我实际花了多少钱。

- 一件 3000 元的羽绒服穿了 60 次 → 每次 50 元
- 一件 199 元的鞋只穿了 2 次 → 每次 99.5 元

标价便宜不等于真便宜，**穿得多的才是真便宜**。

### 在哪儿看

| 位置 | 显示 |
| --- | --- |
| 衣橱卡片左下角 | `¥49.83/次` 角标（可在设置里关掉） |
| 衣物详情页 | 统计卡右侧「单次成本」 |
| 统计页 | 平均单次成本、单次成本最高的那几件 |
| 断舍离页 | 「单次成本偏高」候选清单 |

### 没有数字是怎么回事

- **显示 `—`**：还没填价格
- **显示「还没穿过」**：填了价格但次数是 0

这两种情况都不会拿一个假数字糊弄你，而是把缺什么写清楚。

### 记错了怎么办

进衣物详情页：

- **今天没穿 −1**：记重了减一次
- **改次数**：直接填实际数字（补录以前的穿着记录很方便）
- **今天穿了 +1**：提示条里也带撤销

## 四、衣橱页

### 找衣服

- **搜索**：按名称和备注搜（比如搜「亚麻」「通勤」）
- **分类 / 季节**：上方两排胶囊，点一下筛，再点「全部」取消
- **只看在穿 / 含已处置**：摘要行右侧的胶囊，切一下就能看到已经断舍离掉的衣物

### 排序（摘要行右侧「⇅」）

| 排序 | 什么时候用 |
| --- | --- |
| 最新添加 | 整理刚加进来的一批 |
| 最近穿过 | 看看哪些最近常穿 |
| 穿得最多 | 找常青树 |
| **单次成本高** | **专门用来找「假便宜」** |
| 价格最高 | 回看大件 |
| 买得最晚 | 按购买日期回看 |

选完会记住，下次进来还是这个排序。

### 换个看衣服的方式

- **每行 3 件 / 4 件**：摘要行最右边的方格按钮一点就换（设置里也能改）
- 4 列时一屏能看到更多，适合快速扫一遍

### 批量整理（多选）

右上角 **⋯ → 批量管理**，然后点卡片勾选，底部一排动作：

全选 / 分类 / 季节 / 标签 / 处置 / 删除（横向滑动能看到全部）

适合场景：「这几件都是通勤穿的，一起打个标签」「这季不穿的收起来（处置）」。

## 五、统计页

入口：衣橱页 **⋯ → 统计**，或 设置 → 衣橱统计。

### 概览

在穿 / 已处置 / 没穿过 · 累计花费 · **平均单次成本** · 断舍离回血 · 穿搭记录 / 记录天数 / 今年天数

### 三张榜

| 榜单 | 含义 | 怎么用 |
| --- | --- | --- |
| **衣橱常青树** | 穿得最多的几件 | 这些是你真正该买的东西，以后照这个标准买 |
| **单次成本最高** | 每次穿越贵的 | 「假便宜」清单，考虑穿起来或放手 |
| **很久没穿** | 超过 30 天没上身的 | 提醒你该穿它，或者该断舍离 |

点榜单里的任意一件，直接进这件衣物的详情。

### 分类分布 & 最近 12 个月

- **分类分布**：条形长度按花费画，右边是件数——一眼看出钱都花在哪个类别上
- **最近 12 个月**：按购买日期（没填的按添加时间）统计每个月花了多少

## 六、断舍离

入口：衣橱页 **⋯ → 断舍离**，或 设置 → 断舍离。

### 建议处理

自动帮你挑出三类值得看一眼的衣物：

1. **从没穿过**：买回来超过 30 天、一次都没穿过
2. **单次成本偏高**：每次穿超过 100 元的
3. **很久没穿**：超过 90 天没上身的

每条右边的 **放手** 按钮里有四种处置方式：

| 方式 | 说明 |
| --- | --- |
| 卖掉了 | 可以之后再补一笔「回血金额」，统计里会算净成本 |
| 送人了 | |
| 扔掉了 | |
| 淘汰了 | 起球、变形、破洞这类 |

### 处置 ≠ 删除

处置过的衣物**数据仍然保留**：

- 历史穿搭里照样能看到它
- 在「已处置」标签页里可以随时 **放回衣橱**
- 卖掉的那件还能「记一笔回血金额」，统计里能看到回血合计

只有衣物详情页的「删除」才会真正删数据（含图片），不可恢复。

## 七、标签管理

入口：衣橱页 **⋯ → 标签管理**，或 设置 → 标签管理。

标签是随手写在衣物上的自由文本（比如「通勤」「显瘦」「去年冬天」），
时间久了容易分裂出「白衬衫 / 白色衬衫 / 白衬衣」这种同一个意思的好几种写法。
这一页把它们汇总起来：

- **改名 / 合并**：把「白衬衣」改成「白衬衫」——如果「白衬衫」已经存在，就是**合并**
- **删除**：把标签从所有衣物上摘掉（衣物本身不受影响）
- 列表按使用次数排序，能看到每个标签被几件衣服用着

## 八、试衣间

两个用途：**摆搭配**（做穿搭实验）和 **存灵感**（收藏参考图）。

### 搭配

1. 顶部「搭配」文件夹 → 点 **添加衣物** 把衣橱里的衣服放到画布上
2. 单指拖动位置，**双指捏合缩放 / 旋转**；选中后可以 **置顶 / 置底 / 复位**
3. 摆好点 **保存搭配**，会生成一张合成封面存进「我的搭配」
4. 「我的搭配」里可以按季节筛，点缩略图把那套装回画布继续改；
   **长按缩略图**可以：在画布中打开 / 设置季节 / 删除这套搭配
5. 「复制」把当前这套复制一份，「清空」把画布清空（已保存的搭配不受影响）

> 操作栏（添加衣物 / 复制 / 清空 / 保存搭配）跟着页面滚：往下滑它会走开，把画面让给画布。

### 灵感

1. 顶部 **+** 新建一个文件夹（比如「秋冬灵感」），点它切过去
2. 点 **+ 导入图片** 从相册批量导入参考图
3. **长按图片**进入多选，可以：关联衣物 / 加备注 / 移动 / 删除
4. 长按文件夹胶囊可以重命名或删除文件夹（删除后里面的灵感移到默认文件夹，图片不会丢）

## 九、穿搭日记

### 月历

- 有记录的日期：**记过照片的显示贴图**，没照片的显示一个小圆点
- 点任意一天看那天的记录，上方可以左右切换月份，「回到今天」跳回来

### 当天天气

记下那天的城市、温度、天气，回看穿搭时更有画面感。

- 全部可以**手填**，不依赖任何接口，离线也能用
- 想让它自动获取：去 设置 → 天气 选一个来源（见下）
- 天气来源配好后，打开日记页会自动补上当天天气（只在已经有城市坐标时）

### 当天穿搭

- 每套显示封面 / 衣物缩略图 / 备注 / 季节
- 点 **设封面**：可以用关联衣物的图，也可以从相册选一张
- 点卡片进穿搭详情：看当天照片、关联衣物、**这套是否计入了穿着次数**，
  可以 **分享成卡片图 / 存到相册**、去试衣间继续编辑、编辑或删除

## 十、备份与恢复（重要）

**数据只存在这台手机上**，所以换手机、重装 App 之前一定要先备份。

设置 → 数据：

### 完整备份（推荐）

点「完整备份」，会打包出一个文件夹：

```
点点衣橱-备份-2026-10-16/
    data.json     全部衣物、穿搭、灵感、设置
    images/       所有图片（原图、抠图、封面、当天照片）
```

然后系统弹分享面板，选 **存到「文件」**（或 AirDrop 到自己另一台设备）就行。

### 恢复备份

点「恢复备份」→ 在「文件」里选中那个备份文件夹 → 确认。

> 恢复是**覆盖式**的：会替换当前的全部数据。
> 建议动手前先点一次「完整备份」把现状存一份。

### 导出 JSON

只导出文字数据（**不含图片文件**），适合自己看数据结构或做二次处理。
日常备份请用「完整备份」。

| 天气 | 天气来源 | 系统 WeatherKit（需付费开发者账号）或和风天气（免费 Key） |
| 关于 | 版本 | |

### 天气怎么配

- **不想配**：直接在日记页手填城市 / 温度 / 天气，完全够用
- **和风天气（免费）**：去 dev.qweather.com 申请一个 Key，填进「设置 → 天气 → API Key」，
  填完会自动测一次连通性。老账号 Host 填 `devapi.qweather.com`，新账号用控制台给的专属域名
- **系统 WeatherKit**：不用申请 Key，但需要付费开发者账号，并在开发者后台给 App ID 勾上 WeatherKit 能力

## 十二、隐私与数据

- **不用注册、不用登录**，也没有账号系统
- 所有数据（衣物、穿搭、图片、设置）都存在这台手机的 App 沙箱里，**不会上传**
- **抠图在手机本地完成**（iOS 的 Vision 框架），照片不会离开设备
- 唯一可能联网的地方是**天气**，而且只有你自己配了来源、点了获取才会请求；
  发出去的只有城市坐标，没有你的任何衣物数据
- 卸载 App 会**连数据一起删掉**（所以备份很重要）

## 十三、常见问题

**Q：点图标提示「无法验证 App」或闪一下就退？**
A：这是免费开发者账号签的 App 过了 7 天有效期，不是数据出问题。
手机连上 Mac 重新装一次就好：`./ios/refresh-device.sh`（或 Xcode 里按 ⌘R）。
**续期是覆盖安装，衣物数据不会丢。**

**Q：自动抠图没反应 / 提示不支持？**
A：系统抠图需要 iOS 17 及以上的**真机**（模拟器没有推理后端）。
如果真机上仍失败，用橡皮擦和画笔手动处理也能达到同样效果。

**Q：为什么我加的衣服没有单次成本？**
A：检查两件事：① 填了价格吗；② 记过穿着次数吗（或者用「改次数」直接填一个）。

**Q：在试衣间保存的搭配，为什么没给衣服加次数？**
A：设计如此——试衣间是「摆造型」，不代表今天真的穿了。
要计次数，去「日记 → 添加穿搭」记录。

**Q：删掉一条穿搭记录，衣服的次数会变吗？**
A：会。如果这条记录当初计过次数，删除时会自动把次数减回去，不会留下虚高的数字。

**Q：断舍离之后还能找回来吗？**
A：能。断舍离不删数据，去「断舍离 → 已处置」里点恢复就回到衣橱。

**Q：一天穿了同一件衣服两次？**
A：可以记两条穿搭记录，次数会 +2，这是符合事实的。

## 十四、怎么把它用出效果

这个 App 的价值不在于「记录」，而在于**照出你真正的穿衣习惯**。几个建议：

1. **先坚持记两周**。不用追求完美，点一下卡片 +1、或者睡前拍张照都算。
2. **每月看一次「单次成本最高」和「很久没穿」**。这两张榜就是你的钱包漏水点。
3. **买之前先打开衣橱搜一下**：是不是已经有类似的？上次那件穿了几次？
4. **每年做一次断舍离**。不合适的衣服留在衣橱里不会变成钱，及时放手反而轻松。
5. **别追求把衣服记全**。哪怕只认真记录 30 件最常穿的，数据也足够让你看清自己。

> 衣物有限、选择有限，反而更容易穿得明白。
> 希望它能帮你慢慢靠近那个「零压力衣橱」。
